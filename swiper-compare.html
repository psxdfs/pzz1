把中文需求翻译成参数

老师的要求对应参数说明
无缝循环loop: true首尾相接，滑到最后一张后接第一张
3.2 秒自动翻页autoplay: { delay: 3200 }delay 单位毫秒，3200 = 3.2 秒
手动操作后不停止autoplay: { disableOnInteraction: false }默认 true，用户滑动后自动停止
圆点分页器可点击pagination: { clickable: true }默认 false，圆点只显示不可点
翻页效果 cubeeffect: 'cube'cube / fade / flip / coverflow 等
一轮后自动停止autoplay: { stopOnLastSlide: true }⚠ 仅在 loop: false 时生效
