第一轮 · 盒模型三件套

content-box vs border-box · padding 和 margin 的区别 · border 样式

box-sizing: content-box（默认，宽只算 content）
宽 160 + padding 40 + border 6
= 206px 实际占位
box-sizing: border-box（推荐，宽含 padding + border）
宽 160 = content + padding + border
padding（内边距，撑大元素）vs margin（外边距，推开邻居） padding 10 20 无 padding 
<!-- 盒模型三件套：content-box vs border-box、padding vs margin -->
<div class="r1_demo">
  <span class="label">box-sizing: content-box</span>
  <div data-box="content">宽 160 + padding 40 + border 6 = 206px</div>
</div>

<div class="r1_margin">
  <span class="box a">padding 10 20</span>
  <span class="box b">无 padding</span>
</div>
[data-box] {
  width: 160px; height: 100px;
  padding: 20px; margin: 6px;
  border: 3px dashed #e9785c;
}
[data-box="content"] { box-sizing: content-box; }  /* 默认 */
[data-box="border"]  { box-sizing: border-box;  }  /* 推荐 */

.box.a { padding: 10px 20px; }  /* 内边距撑大自身 */
.box.b { padding: 0;          }
.box    { margin: 0 10px;   }  /* 外边距推开邻居 */

第二轮 · 层叠优先级可视化

选择器优先级标签 < 类 < id · 后代选择器叠加 · !important 一锤定音

选择器优先级：标签 < 类 < id
这行文字依次被三层选择器染色 —— 最终是 id 的橙色
后代选择器层数越多优先级越高
我是双层后代 .a .b —— 加粗
我是单层 .b —— 不加粗
!important：谁带谁赢（独立于优先级）
同一个 .c：前面蓝色 !important 压掉后面绿色普通声明
<!-- 层叠优先级：标签 < 类 < id -->
<div class="tag-sel cls-sel" id="r2_id">
  三层选择器都命中 → 最终以 id 橙色为准
</div>

<!-- 后代选择器叠加 —— .a .b 两层比单层 .b 优先 -->
<div class="a">
  <span class="b">我是双层后代 .a .b</span>
</div>
<span class="b">我是单层 .b</span>

<!-- !important 一锤定音，与选择器优先级无关 -->
<div class="c">同一个 .c</div>
/* 1. 标签 < 类 < id */
.tag-sel { color: #60a5fa; }  /* 最底 */
.cls-sel { color: #34d399; }  /* 覆盖标签 */
#r2_id   { color: #e9785c; }  /* 覆盖类 */

/* 2. 后代叠加：层数越多越优先 */
.a .b  { font-weight: 700;  }
.b     { font-weight: normal; }

/* 3. !important 独立于优先级，谁带谁赢 */
.c { color: #60a5fa !important; }  /* 先写但带 !important */
.c { color: #34d399; }           /* 后写也被压掉 */
