第一轮 · 盒模型三件套

content-box vs border-box · padding 和 margin 的区别 · border 样式

box-sizing: content-box（默认，宽只算 content）
宽 160 + padding 40 + border 6
= 206px 实际占位
box-sizing: border-box（推荐，宽含 padding + border）
宽 160 = content + padding + border
padding（内边距，撑大元素）vs margin（外边距，推开邻居） padding 10 20 无 padding 
<!-- 盒模型三件套：content-box vs border-box、padding vs margin -->
<div class="r1_demo">
  <span class="label">box-sizing: content-box</span>
  <div data-box="content">宽 160 + padding 40 + border 6 = 206px</div>
</div>

<div class="r1_margin">
  <span class="box a">padding 10 20</span>
  <span class="box b">无 padding</span>
</div>
[data-box] {
  width: 160px; height: 100px;
  padding: 20px; margin: 6px;
  border: 3px dashed #e9785c;
}
[data-box="content"] { box-sizing: content-box; }
[data-box="border"]  { box-sizing: border-box;  }

.box.a { padding: 10px 20px; }
.box.b { padding: 0;          }
.box    { margin: 0 10px;   }

第二轮 · 层叠优先级可视化

选择器优先级标签 < 类 < id · 后代选择器叠加 · !important 一锤定音

选择器优先级：标签 < 类 < id
这行依次被三层选择器染色 —— 最终是 id 的橙色
后代选择器层数越多优先级越高
我是双层后代 .a .b —— 加粗
我是单层 .b —— 不加粗
!important：谁带谁赢（独立于优先级）
同一个 .c：前面蓝色 !important 压掉后面绿色普通声明
<!-- 层叠优先级：标签 < 类 < id -->
<div class="tag-sel cls-sel" id="r2_id">三层都命中 → 最终 id 橙色</div>

<!-- 后代叠加：.a .b 两层比单层 .b 优先 -->
<div class="a">
  <span class="b">双层后代 .a .b</span>
</div>
<span class="b">单层 .b</span>

<!-- !important 独立于优先级，谁带谁赢 -->
<div class="c">同一个 .c</div>
/* 1. 标签 < 类 < id */
.tag-sel { color: #60a5fa; }
.cls-sel { color: #34d399; }
#r2_id   { color: #e9785c; }

/* 2. 后代叠加：层数越多越优先 */
.a .b  { font-weight: 700;  }
.b     { font-weight: normal; }

/* 3. !important 独立于优先级 */
.c { color: #60a5fa !important; }
.c { color: #34d399; }

第三轮 · 继承 vs 非继承可视化

继承来的属性（font、color）被子元素自动继承 · 不继承的（margin、padding、border）必须自己写

我是父元素 r3_parent： font-size:14px · color:#245b4f · 背景/边框/padding/margin 是我自己的 ● 子元素 1：r3_child-inherit —— font-size 和 color 都「继承」父元素 ● 子元素 2：r3_child-needs-own —— 背景/边框/padding/margin 必须自己写，不继承 
<!-- 继承 vs 非继承 -->
<div class="r3_parent">
  我是父元素：font-size/color 会被继承；背景/边框/padding/margin 不会被继承
  <span class="r3_child-inherit">子1 继承父的 font-size 和 color</span>
  <span class="r3_child-needs-own">子2 不继承的属性要自己写</span>
</div>
/* 父元素：font、color 会被子元素继承；padding/border/margin 不会 */
.r3_parent {
  font-size: 14px;      /* ← 会被子元素继承 */
  color: #245b4f;      /* ← 会被子元素继承 */
  background: #fff4e6;  /* ← 不继承 */
  padding: 12px;       /* ← 不继承 */
  border: 2px dashed #245b4f; /* ← 不继承 */
  margin: 0;            /* ← 不继承 */
}

/* 子元素 1：自己只写 font-weight，font-size/color 从父继承 */
.r3_child-inherit {
  font-style: italic;
  font-weight: bold;
}

/* 子元素 2：不继承的属性必须自己写 */
.r3_child-needs-own {
  background: #ffe4d6;
  padding: 6px 10px;
  border: 1px solid #e9785c;
  margin: 8px 0;
}
