第二轮 · 精确提示词

命中 4/4 需求 —— 每条都给精确值 + 对应需求号

① 无缝循环（loop: true）
② autoplay 设 delay 为 3200 毫秒、只播放一轮后停止（stopOnLastSlide: true）

④ effect: 'cube'，cubeEffect 用默认参数即可

/* 第二轮 · AI 输出（精确提示词） */
const mySwiper = new Swiper('#mySwiper', {
    // 需求④：初始效果为 cube
    effect: 'cube',
    cubeEffect: { slideShadows: false },

    // 需求①：无缝循环
    loop: true,

    // 需求②：3.2 秒自动翻页后停止
    autoplay: {
        delay: 3200,
        stopOnLastSlide: true,
        disableOnInteraction: false,
    },

    // 需求③：圆点分页器可点击
    pagination: {
        el: '.swiper-pagination',
        clickable: true,
    },
});
/* 第二轮 vs 第一轮 · 关键改进 */
粗： autoplay: true
精： autoplay: { delay: 3200, stopOnLastSlide: true }
       ↑ 给了精确数字 3200ms，还加了"停在最后一页"

粗： 没有标注每个配置对应哪个需求
精： 每条前面写 // 需求④ / 需求① —— AI 输出即自查清单

粗： loop: true 就完事
精： 明确是 Swiper 8 写法，给 pagination.el 完整路径，加 disableOnInteraction 防止用户一停就不自动
